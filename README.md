# Mobile

Ung dung React Native cho he thong quan ly su co va bao tri thiet bi.

## Cong nghe

- React Native
- TypeScript

## Cau truc chinh

- `src/screens`: cac man hinh cua ung dung.
- `src/components`: component dung chung.
- `src/navigation`: cau hinh dieu huong sau nay.
- `src/services`: noi dat cac ham goi REST API sau nay.
- `src/hooks`: custom hooks.
- `src/types`: TypeScript interfaces/types.
- `src/utils`: ham tien ich.
- `src/constants`: hang so dung chung.
- `assets`: hinh anh, icon va tai nguyen tinh.

## Lenh co ban

```bash
npm start
npm run android
npm run ios
npm run lint
npm test
```
